# RepoGuardian · 双侧对照

两侧开放的源码边界围绕中心菱形，呼应 Base / Head 对照与围绕证据进行核验的审查方式。图形表达专注与守护，不表达“审查后保证没有缺陷”。

主标由三个闭合实色路径构成；所有正式字标已转曲。SVG 母版不依赖字体，也不含位图、滤镜、阴影或外部资源。

## 尺寸与留白

- 标准符号：建议 32px 及以上；16–32px 优先使用 `symbol-small`。小尺寸版加大中心菱形，并将边界放到整数像素网格。
- 横向组合：建议宽度至少 160px。空间不足时只使用符号，名称保留为界面中的普通文字。
- 竖向组合：建议宽度至少 180px。
- 以标准符号中边界厚度为留白单位 U，即 256 画布中的 32 单位。从实际图形最外沿向四周至少保留 1U；已有 viewBox 边距不一定构成完整留白。
- 横向组合内，图形与字标的间隔为 48 单位；保持原有相对比例。
- 反白符号将边界从 32 减至 30 单位、中心菱形宽度从 48 减至 44 单位，减轻深色背景上的视觉膨胀。
- 印刷最小尺寸尚未打样；屏幕检查结果不能直接作为纸张、刺绣或雕刻生产的验收依据。

## 配色

| 名称 | HEX | RGB | CMYK 近似值 |
| --- | --- | --- | --- |
| Guardian Green · 主色 | `#07866F` | 7, 134, 111 | 95, 0, 17, 47 |
| Source Ink · 字标/深色底 | `#142C2A` | 20, 44, 42 | 55, 0, 5, 83 |
| Mint · 深色底辅助色 | `#78DCBF` | 120, 220, 191 | 45, 0, 13, 14 |
| Paper · 辅助底色 | `#F6FAF8` | 246, 250, 248 | 2, 0, 1, 2 |

优先使用绿符号配深墨字标的主版本。深墨或主绿色背景使用白色版本；单色制作使用 black 或 mono。Mint 主要用于深色背景，不作为浅色背景上的小字颜色。

CMYK 为无 ICC 配置的数学近似值，不是印刷标准。未指定 Pantone，不提供未经实物比色的色号。

## 字标与字体

字标以本机 Bahnschrift Bold 为基础调整字距，再转成闭合路径。对比稿见 `preview/type-study.png`；正式母版不含可编辑文字，不需要安装字体。套件不包含字体文件；如需分发、嵌入字体或扩展为品牌字体，应另行核对相应字体授权。

不要通过重新输入名称来重建字标，也不要单独压扁或拉宽字标。

## 网页资源

`web/` 包含 16/32/48px favicon PNG、三尺寸 ICO、SVG favicon、180px Apple 图标、192/512px Web 图标、512px maskable 图标及 manifest。

`head-snippet.html` 假定图标位于站点根目录；接入子路径站点时按实际部署路径调整。应用图标和 maskable 图标使用完整实色底；maskable 版本留出较大的安全区。

manifest 和图标只是静态接入材料，不代表项目已经实现离线、安装或其他 PWA 行为。本次没有修改应用源码、README 或站点配置。

## 使用限制与交付说明

保持图形方向、比例、间距和中心菱形；使用批准的单色版本。不要旋转、添加渐变或投影、把中心换成对勾，或把两侧边界单独挪动。

展示中的 README、网站、应用图标、终端配色、贴纸和社交资料均为品牌使用示意，不是当前产品截图或功能声明。没有建立真实 CLI、发布产品版本或创建社交账户。

本套件未完成商标近似检索、专业商标清查或实物印刷打样。没有输出 AI、EPS 或印刷 PDF；可直接使用 SVG 进行后续矢量编辑。
